# Hourstone Companion 0.1.0

Initial Windows development preview with a character overview, local read-only
Hourstone ingestion and optional device exchange through a shared provider folder.

Requires Windows 11 x64 and Hourstone 0.2.0. Initial creation of the data addon
requires a complete WoW restart. Later data refreshes load on login or reload.

Automated core, contract and rendering checks are available in this repository.
Practical verification in live WoW clients, on two provider-connected Windows
devices, and with signed installation/update packages is required before a public release.
