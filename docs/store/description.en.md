# Hourstone Companion – English Store description

## Short description

View your WoW characters' playtime and Retail progress, with optional synchronization between your PCs.

## Description

Hourstone Companion adds a Windows overview to the separate “Hourstone – Azeroth Hours” WoW addon.

Compare saved playtime, search for characters or guilds, and filter by realm and WoW client. For Retail, see your saved keystone, weekly best and all nine Great Vault slots. Character details distinguish unknown, confirmed-empty and outdated values and show when progress was recorded.

If you use several PCs, select a locally available folder managed by Dropbox, OneDrive, Proton Drive or another file synchronization service. Your service transfers the files; Hourstone combines the saved observations and prepares them for the addon. The local overview also works without a shared folder.

No additional Hourstone account is required. The app reads saved addon data locally. New observations become available after WoW saves them when you log out or use `/reload`.

## Features

- Character overview with guilds, playtime, search, realm and client filters.
- Separate Retail progress view with keystone, weekly best and Great Vault details.
- Hide and restore characters in the overview, including across your own PCs.
- Optional folder synchronization without a Hourstone server or Hourstone sign-in.
- Background operation from the Windows notification area and optional Windows startup.
- German and English; dark, light and Windows-controlled appearance.
- Updates for this Store edition through Microsoft Store.

## Requirements

Windows 11 on an x64 PC. World of Warcraft and the Hourstone addon are required separately to record your own game data. Supported clients are Retail, Mists Classic, TBC Anniversary and Classic Era; the progress view is for Retail.

Playtime, guilds and visibility require Hourstone 0.2.2 or later. Local Retail progress can be read from addon 0.3.1; sending progress back into WoW requires addon 0.3.2 with protocol-4 support. All participating Companions must use version 0.2.0 for the new exchange between PCs. The addon is updated separately.

For optional exchange, keep the selected sync folder permanently available locally on every PC. An external synchronization service has its own setup, account requirements and possible costs.

Hourstone is an independent project and is not affiliated with Blizzard Entertainment. World of Warcraft is a product of Blizzard Entertainment.
